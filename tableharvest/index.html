TableHarvest

Export any table on a web page to Excel, CSV or Google Sheets in one click. Merged cells, data grids and paginated tables included. Nothing is uploaded anywhere: the file is built inside your browser.

What it does, free and unlimited

  • Finds every table on the page: regular HTML tables, div-based data grids (ARIA grids), CSS tables and tables inside frames.
  • An "Export" badge on each table, or right-click > "Export this table".
  • Preview before exporting, with the exact rows and columns you will get.
  • Copy for Excel / Google Sheets: paste with Ctrl+V and it lands as a grid with real numbers, in any spreadsheet language.
  • Download CSV with the separator your Excel expects (comma, or semicolon for Spanish, Portuguese, German and French Excel) and the encoding you need.
  • Merged cells (rowspan / colspan) are laid out correctly. Line breaks inside cells are kept.
  • Header rows detected automatically; you can override them. Optional: only visible rows, include link URLs.
  • Form fields inside tables (inputs, checkboxes, dropdowns) export their current value.

Questions

Does it send my data anywhere?

No. Tables are read and converted inside your browser. The only network requests are the license check when you activate Pro and, if you choose to connect it, Google Sheets. See the privacy policy.

My Excel is in Spanish / Portuguese / German. Will numbers work?

Yes. Each number is copied with its real value, so "1,425,423,212" is a number in any spreadsheet language, and you can pick the CSV separator your Excel expects.

A table does not export the way I expect.

Write to support with the page address. Tables that do not export are fixed in the next version.

Can I use one key on several computers?

Yes, up to three activations per key. Deactivate a computer from Settings to free a slot.
